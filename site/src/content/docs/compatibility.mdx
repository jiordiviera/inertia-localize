| Requirement | Versions |
| --- | --- |
| PHP | &ge;8.2 |

| `inertiajs/inertia-laravel` | ^2.0 &#124; ^3.0 |

| Requirement | Versions |
| --- | --- |
| `react` | ^16.9.0 &#124; ^17.0.0 &#124; ^18.0.0 &#124; ^19.0.0 |
| `@inertiajs/react` | ^2.0.0 &#124; ^3.0.0 |

## `@inertia-localize/vue`

| Requirement | Versions |
| --- | --- |
| `vue` | ^3.0.0 |
| `@inertiajs/vue3` | ^2.0.0 &#124; ^3.0.0 |

`@inertia-localize/core` has no peer dependencies &mdash; it's plain TypeScript shared by both
adapters.
