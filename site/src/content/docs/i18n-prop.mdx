# The i18n shared prop

The package automatically shares an `i18n` prop on every Inertia response — no controller
changes needed. It is available on the initial server-rendered page without a client fetch, and
is included in partial reloads.

```php
'i18n' => [
    'locale' => 'fr',
    'fallback' => 'en',
    'locales' => [
        ['code' => 'en', 'name' => 'English'],
        ['code' => 'fr', 'name' => 'Français'],
    ],
    'messages' => [
        'actions.save' => 'Enregistrer',
    ],
]
```

| Field | Description |
| --- | --- |
| `locale` | The active locale for this request |
| `fallback` | The configured fallback locale |
| `locales` | Every supported locale from config, as `{ code, name }` |
| `messages` | Flattened dot-key messages for the active locale's configured groups |

If `i18n` is missing from a page's props, confirm the route uses Inertia and Laravel's
session-enabled `web` middleware group — `SetLocale` and the prop sharing both depend on it.
